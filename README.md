# Personal Portfolio — Fausto Martin Sosa

My personal developer portfolio built with React + Vite + Bootstrap. Dark terminal-style design showcasing who I am, my tech stack, and my projects.

**Live:** _coming soon_

## Tech Stack

- React 19 + Vite
- Bootstrap 5
- Custom CSS (terminal / hacker theme)

## Sections

- **Hero** — animated typing effect
- **About** — bio and current status
- **Skills** — tech stack grouped by category
- **Projects** — real projects with links to repos and live demos
- **Contact** — GitHub, LinkedIn, email

## Local Development

```bash
npm install
npm run dev
```
